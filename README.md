# Teleprompter

En enkel teleprompter der kører i browseren og kan lægges på telefonens hjemmeskærm som en app.

**Åbn appen:** https://martinmoller8.github.io/Teleprompter/

## Læg den på telefonen
- **iPhone:** Åbn linket i Safari → tryk Del → "Føj til hjemmeskærm".
- **Android:** Åbn linket i Chrome → menuen (⋮) → "Installér app" / "Føj til startskærm".

Når appen har været åbnet én gang, virker den også uden netforbindelse.
